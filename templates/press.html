What it is

Space Radar is a web page. It reads public catalogues (orbital elements, ephemerides, launch schedules, space weather) and works out, in the visitor's own browser, where each thing is this second. A visitor can search for an object, follow it, read a short card about it, see when it passes over them, or take a guided trip that flies the camera from stop to stop.

It is built to be honest about what it shows. Every drawn thing is measured, modelled or illustrative, and says which; every number names its source and how old it is.

How to cite it

Space Radar contributors. Space Radar: a live 3D map of space in the browser. https://www.spaceradar.ai (MIT licence). Source code: github.com/Sara-Managed-Projects/space-radar. A machine-readable citation is in CITATION.cff, which GitHub turns into a "Cite this repository" button. Please add the date you looked, and cite the data's own publishers for any number you quote from a card.

Embed one live object

A story can carry one live object in a frame: the scene, the object's tag and a link back. The embedding guide has the snippet and the parameters; in the app it is Share, then Embed.
